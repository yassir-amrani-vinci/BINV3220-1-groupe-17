# Bilan — semaine 6

## Qu’ai-je appris ?
J’ai appris à partir d’un template GitHub, à préparer une branche de travail, à initialiser le projet avec les bonnes commandes, puis à valider progressivement une fonctionnalité avec les tests et les contrôles qualité. J’ai aussi vu qu’il faut vérifier chaque modification du code et de la documentation plutôt que de faire confiance à l’agent sans lecture.

## Ce qui a bien fonctionné ?
Le découpage par couche a été clair : backend, service, repo, tests puis frontend. Les commandes de validation (`npm run check`) et les tests ciblés ont permis de corriger rapidement les écarts. La lecture de l’architecture et de la documentation a aussi évité de modifier des fichiers hors périmètre.

## Ce qui a moins bien fonctionné ?
La première difficulté a été de repérer le bon dépôt et la bonne branche, puis d’installer le bon environnement Node pour le projet. Il a aussi fallu faire attention à ne pas mélanger le dépôt GitLab initial avec le dépôt GitHub du cours et ne pas créer de modifications inutiles.
