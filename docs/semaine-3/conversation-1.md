# Conversation 1 — semaine 3

Cette archive résume fidèlement le travail réalisé dans cette conversation. Pour
répondre à l'exigence d'archivage complète du devoir, elle peut être remplacée par
l'export **Copy All** de VS Code sans modifier les autres livrables.

## Demande

L'objectif demandé était de prendre connaissance du projet puis de préparer la
soumission de la semaine 3 : créer une PR selon les consignes du cours et ajouter
dans le dossier de semaine 3 les matrices de guides/senseurs, de traçabilité des
tests, les conversations et le bilan.

## Analyse effectuée

- Le dépôt a été inspecté comme un monorepo npm comprenant un backend Express/SQLite
  et un frontend React/Vite.
- L'architecture, le cahier des charges, l'API, les conventions Copilot, les tests et
  les données de démonstration ont été lus.
- Le dépôt distant a été synchronisé : les travaux des semaines précédentes sont
  fusionnés dans `main`, notamment les candidatures de la semaine 7.
- Une branche `semaine-3` a été créée depuis le `main` distant à jour.

## Décisions

- Les livrables sont placés sous `docs/semaine-3/`, conformément à la structure déjà
  utilisée par les semaines précédentes. Le chemin `./dos/semaine-3` de la consigne
  est interprété comme une coquille pour `./docs/semaine-3`.
- Les crédits Copilot ne sont pas estimés : ils restent à compléter à partir des
  statistiques réelles de chaque membre.
- Les requirements non implémentés sont marqués « non couverte » ou « partielle »
  plutôt que présentés comme validés.
